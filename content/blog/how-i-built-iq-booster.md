# How I Built IQ Booster

A good game does not need a complicated premise. It needs a clear interaction, understandable rules, meaningful feedback, and a reason to try one more round. That idea guided my work on **IQ Booster**, a brain-training game project in my portfolio.

## Starting With the Core Loop

The first question I asked was simple: **what should the player repeatedly do?** A useful core loop can be described as action → feedback → result → next challenge. Keeping that loop short makes the game easy to learn and gives the player immediate information about whether they are improving.

For a puzzle or brain-training experience, the challenge must feel fair. The player should understand why an answer was correct or incorrect, and the next question should feel like a natural continuation rather than a completely unrelated task.

## Designing Difficulty

Difficulty is one of the most important parts of a thinking game. If every challenge is easy, the player becomes bored. If the difficulty jumps too aggressively, the player feels punished.

A better approach is to increase complexity gradually. Early rounds can establish the mechanic, middle rounds can introduce combinations or time pressure, and later rounds can test the player's ability to apply the same idea under greater cognitive load.

## Feedback Matters

Small interactions carry a lot of emotional weight in games. A correct answer should feel different from an incorrect answer. A score should be visible without overwhelming the screen. A player should always know what just happened.

I therefore treat visual feedback, timing, sound, score presentation, and transitions as part of the game mechanics rather than decoration.

## What I Learned

The biggest lesson from IQ Booster is that game development is less about adding features and more about refining the **feel of the loop**. A small set of mechanics that respond quickly and clearly can be more satisfying than a large feature set that lacks cohesion.

That lesson now influences how I approach every interactive product: define the action, make feedback immediate, reduce friction, and give the user a meaningful next step.
